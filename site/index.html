LeafMD

Read and edit markdown your way

A markdown editor for Linux that's simple on purpose. Every feature is easy to find and obvious to use, so you can focus on your writing instead of learning the app.

Three ways to look at a document

Switch between them with one click, or a keyboard shortcut.

The essentials, done well

No plugins to manage, panels to arrange or settings to tune. Just a dependable app that feels obvious from the moment you open it.

  • Three views

    Formatted for distraction-free reading, raw for writing, or both side by side. Switch with one click.

  • Live preview

    The formatted side updates as you type, and both sides scroll together so you never lose your place.

  • A formatting bar

    Bold, links, lists, headings and tables, added for you. A built-in cheatsheet shows the syntax.

  • Smart typing

    Lists carry on when you press Enter, and pasting a web address over some text turns it into a link.

  • Find and replace

    Search the raw or formatted text, with a count of every match. Replace one, or all at once.

  • GitHub-style markdown

    Tables, checklists, footnotes and strikethrough all work, and scripts inside a document never run.

Install LeafMD

Once it's installed, updates arrive through your app store, like any other app.

With your app store

Click Install, then open the small file it downloads. Your app store shows LeafMD, ready to install.

Install

From a terminal

One command installs LeafMD and keeps it updated:

flatpak install {{base_url}}LeafMD.flatpakref

As a file

Every version is also a .flatpak file on GitHub. Open it with your app store, and it updates from here.

Download from GitHub

Install works with app stores that support Flatpak, like GNOME Software and KDE Discover. If nothing opens the file, use the terminal command. LeafMD needs a Linux computer with Flatpak set up, on a 64-bit Intel or AMD processor (x86_64). The GNOME parts it needs come from Flathub, which is added for you if it isn't already. Everything LeafMD installs is signed, so updates can only come from its developer.
