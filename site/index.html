LeafMD

Read and edit markdown your way

A markdown editor for Linux that's simple on purpose. Every feature is easy to find and obvious to use, so you can focus on your writing instead of learning the app.

Features

The essentials, done well

Great out of the box. The few options stay out of the way, so you can focus on reading and writing.

Formatting without the syntax

Bold, links, lists, headings and tables are one click away on the formatting bar, so you don't need to remember how markdown writes them.

  • Drop an image onto the text to link it
  • A built-in cheatsheet covers the rest
  • Misspelt words are underlined as you type

Looks the way it does on GitHub

Tables, checklists, footnotes and coloured code blocks show the way they do on GitHub.

  • Print it, or export it as a PDF or web page
  • Scripts never run, so opening a document is safe
  • Light or dark, and the fonts and text size are yours

  • Tabs and folders

    Several documents in one window, with your folder and headings in a side panel.

  • Find and replace

    Every match highlighted and counted, in the raw or formatted text.

  • Safe from other apps

    If another app changes your file, you choose: reload it, or keep your version.

  • Distraction Free

    Hide everything but your words when it's time to concentrate.

Install LeafMD

Once it's installed, updates arrive through your app store, like any other app.

Setting up Flatpak on Ubuntu

Ubuntu doesn't include Flatpak, so it needs setting up once.

  1. Install Flatpak, and the Software app that opens LeafMD's install file:

    sudo apt install flatpak gnome-software-plugin-flatpak

  2. Add Flathub, where the parts LeafMD needs come from:

    flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

  3. Restart your computer. After that, the Install button works.

More about Flatpak on Ubuntu

Did the file open in a text editor?

Flatpak isn't set up yet. On Ubuntu, follow the steps above. Elsewhere, see flatpak.org/setup.

Which app stores work?

Any that support Flatpak, like GNOME Software and KDE Discover.

What do I need?

Linux with Flatpak, on a 64-bit Intel or AMD processor (x86_64). Anything else LeafMD needs comes from Flathub, which is added for you.

Where do updates come from?

Everything LeafMD installs is signed, so updates can only come from its developer.

Terminal

Use LeafMD from a terminal

Flatpak apps don't come with a short command, but one line adds it. After that, leafmd notes.md opens that file, and leafmd . opens the folder you're in.

For everyone on this computer. Needs your admin password:

sudo sh -c 'set -C; printf "%s\n" "#!/bin/sh" "while case \"\$1\" in -*) ;; *) false ;; esac; do o=\"\$o \$1\"; shift; done" "exec flatpak run --file-forwarding io.github.jeremehancock.LeafMD \$o @@ \"\$@\" @@" > /usr/local/bin/leafmd && chmod 755 /usr/local/bin/leafmd'

Just for your account. No admin password needed:

sh -c 'set -C; mkdir -p ~/.local/bin; printf "%s\n" "#!/bin/sh" "while case \"\$1\" in -*) ;; *) false ;; esac; do o=\"\$o \$1\"; shift; done" "exec flatpak run --file-forwarding io.github.jeremehancock.LeafMD \$o @@ \"\$@\" @@" > ~/.local/bin/leafmd && chmod 755 ~/.local/bin/leafmd'
Which versions does it work with?

All of them. With the latest, your terminal is free as soon as LeafMD opens. Older versions keep it busy until LeafMD closes.

Already have a leafmd?

Neither line replaces it. You'll just see an error.

Set this up before?

If leafmd --new-window says "Failed to open", delete the old file and run the line again.

Is leafmd not found?

If you used the "Just for you" line, log out and back in. If it's still missing, add ~/.local/bin to your PATH.

How do I undo it?

Delete the file it made: /usr/local/bin/leafmd (with sudo rm) or ~/.local/bin/leafmd.

Early days

LeafMD is a young app in active development. It's ready for everyday writing, but you may run into the odd rough edge, and things can change from one version to the next.
