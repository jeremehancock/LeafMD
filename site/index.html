LeafMD

Read and edit markdown your way

A markdown editor for Linux that's simple on purpose. Every feature is easy to find and obvious to use, so you can focus on your writing instead of learning the app.

Early days. LeafMD is a young app in active development. It's ready for everyday writing, but you may run into the odd rough edge, and things can change from one version to the next. Ideas and bug reports are always welcome, and the roadmap shows what's coming.

Three ways to look at a document

Switch between them with one click, or a keyboard shortcut.

The essentials, done well

Great out of the box. The few options stay out of the way, so you can focus on reading and writing.

  • Three views

    Formatted for reading, raw for writing, or both side by side as you type. Distraction Free hides the rest, and light or dark, the fonts and the text size are yours.

  • Tabs and folders

    Keep several documents open in one window. A side panel shows your folder and headings, so the next file or section is one click away.

  • A formatting bar

    Bold, links, lists, headings and tables, added with a click so you don't need to remember the syntax. Drop an image onto the text to link it. A built-in cheatsheet covers the rest, and misspelt words are underlined as you type.

  • Find and replace

    Search the raw or formatted text, with every match highlighted and counted. Step through them one by one, then replace one or all at once.

  • Safe from other apps

    If another app changes a file you have open, a banner lets you reload it or keep your version. Nothing is overwritten without asking first.

  • GitHub-style markdown

    Tables, checklists, footnotes and coloured code blocks show the way they do on GitHub, on screen, printed, or exported as a PDF or web page. Scripts never run, so opening one is safe.

Install LeafMD

Once it's installed, updates arrive through your app store, like any other app.

With your app store

Click Install, then open the small file it downloads. Your app store shows LeafMD, ready to install.

Install

From a terminal

One command installs LeafMD and keeps it updated:

flatpak install {{base_url}}LeafMD.flatpakref

As a file

Every version is also a .flatpak file on GitHub. Open it with your app store, and it updates from here.

Download from GitHub

Setting up Flatpak on Ubuntu

Ubuntu doesn't include Flatpak, so it needs setting up once.

  1. Install Flatpak, and the Software app that opens LeafMD's install file:

    sudo apt install flatpak gnome-software-plugin-flatpak

  2. Add Flathub, where the parts LeafMD needs come from:

    flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

  3. Restart your computer. After that, the Install button works.

More about Flatpak on Ubuntu

  • Did the file open in a text editor? Flatpak isn't set up yet. On Ubuntu, see the steps above. For other systems, see flatpak.org/setup.
  • Which app stores work? Any that support Flatpak, like GNOME Software and KDE Discover.
  • What you need A Linux computer with Flatpak set up, on a 64-bit Intel or AMD processor (x86_64). The GNOME parts LeafMD needs come from Flathub, which is added for you if it isn't already.
  • Signed updates Everything LeafMD installs is signed, so updates can only come from its developer.

Use LeafMD from a terminal

Flatpak apps don't come with a short command, but one line adds it. After that, typing leafmd notes.md opens that file in LeafMD, and leafmd . opens the folder you're in.

For everyone on this computer

Asks for your admin password, and works straight away on most systems:

sudo sh -c 'set -C; printf "%s\n" "#!/bin/sh" "while case \"\$1\" in -*) ;; *) false ;; esac; do o=\"\$o \$1\"; shift; done" "exec flatpak run --file-forwarding io.github.jeremehancock.LeafMD \$o @@ \"\$@\" @@" > /usr/local/bin/leafmd && chmod 755 /usr/local/bin/leafmd'

Just for you

No admin password needed:

sh -c 'set -C; mkdir -p ~/.local/bin; printf "%s\n" "#!/bin/sh" "while case \"\$1\" in -*) ;; *) false ;; esac; do o=\"\$o \$1\"; shift; done" "exec flatpak run --file-forwarding io.github.jeremehancock.LeafMD \$o @@ \"\$@\" @@" > ~/.local/bin/leafmd && chmod 755 ~/.local/bin/leafmd'
  • Works with every version It works best with the latest, which gives your terminal back as soon as LeafMD opens. On older versions, files open the same way, but the terminal stays busy until LeafMD closes.
  • Already have a leafmd? Neither line replaces it. You'll see an error, and nothing changes.
  • Set this up before? If options like leafmd --new-window say "Failed to open" in folders outside your home folder, delete the old file and use the line again. Opening files works either way.
  • Is leafmd not found? After using the "Just for you" line, log out and back in. If it still isn't found, add ~/.local/bin to your PATH.
  • To undo the setup Delete the file the line created: /usr/local/bin/leafmd (with sudo rm) or ~/.local/bin/leafmd.
